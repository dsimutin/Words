# Words Telegram Bot

Простой Telegram-бот для изучения английских слов через флеш-карточки.

Проект сделан так, чтобы человек без опыта в кодировании мог запустить его на Mac почти без терминала.

## Что умеет бот

- показывает карточку со словом и транскрипцией;
- по кнопке показывает перевод;
- принимает ответ: `Запомнил` / `Не запомнил`;
- хранит слова в SQLite-базе;
- импортирует слова из папки `words/`;
- дает администратору панель `/admin`;
- позволяет добавлять, редактировать и удалять слова прямо в Telegram.

## Самый простой запуск на Mac

1. Скачай репозиторий на компьютер.
2. Открой файл `START_HERE.txt`.
3. Запусти `install_mac.command`.
4. В открывшемся файле `.env` вставь токен бота и свой Telegram ID.
5. Запусти `run_mac.command`.

## Где брать токен бота

1. В Telegram открой `@BotFather`.
2. Напиши `/newbot`.
3. Создай бота.
4. Скопируй токен.
5. Вставь его в `.env` в строку:

```env
BOT_TOKEN=сюда_токен
```

## Где брать Telegram ID

1. В Telegram открой `@userinfobot`.
2. Нажми Start.
3. Скопируй свой ID.
4. Вставь его в `.env` в строку:

```env
ADMIN_ID=123456789
```

## Формат слов

Файлы со словами лежат в папке `words/`.

Пример:

```text
apple - [ˈæpəl] - яблоко
book - [bʊk] - книга
house - [haʊs] - дом
```

Каждое слово — с новой строки.

## Команды бота

Для пользователя:

- `/start` — открыть меню;
- `/train` — начать тренировку;
- `/stats` — посмотреть статистику.

Для администратора:

- `/admin` — открыть админ-панель.

## Важно

Файл `.env` нельзя загружать на GitHub, потому что там будет секретный токен бота.

В репозитории лежит только безопасный шаблон `.env.example`.
