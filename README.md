# Words Flashcards Telegram Bot

Simple Telegram bot for learning English words with flashcards.

Stack:
- Python
- aiogram 3
- SQLite

Run on Mac:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python bot.py
```

Admin panel: `/admin`

Words format:

```text
apple - [ˈæpəl] - яблоко
book - [bʊk] - книга
house - [haʊs] - дом
```
